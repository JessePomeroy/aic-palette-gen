# Artwork card fonts

Self-hosted, unmodified font files from Google Fonts. They are used only by the
artwork card and embedded into its PNG export; visitors make no font requests to
Google.

- Allura, weight 400: [upstream project](https://github.com/googlefonts/allura),
  [download](https://fonts.gstatic.com/s/allura/v23/9oRPNYsQpS4zjuAPjA.ttf).
  License: `Allura-OFL.txt`.
- Dancing Script, weight 500:
  [upstream directory](https://github.com/google/fonts/tree/main/ofl/dancingscript),
  [download](https://fonts.gstatic.com/s/dancingscript/v29/If2cXTr6YS-zF4S-kcSWSVi_sxjsohD9F50Ruu7BAyoHTQ.ttf).
  License: `Dancing-Script-OFL.txt`.
